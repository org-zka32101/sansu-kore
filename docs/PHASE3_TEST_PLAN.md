### 3️⃣ パフォーマンステスト

#### 3.1 メモリ使用量
```
目標値:
- アプリ初期化時: < 200MB
- ステージロード時: < 50MB追加
- 全ステージメモリ合計: < 400MB
```

**測定方法:**
```bash
flutter run --profile
# Android Studio Profiler でメモリ監視
# または adb shell dumpsys meminfo
```

#### 3.2 フレームレート
```
目標値:
- ステージ選択スクロール: 60 FPS (30ms/frame以内)
- クエスト画面: 60 FPS
- 結果画面アニメーション: 60 FPS
```

**測定方法:**
```bash
flutter run --profile
# Android Studio Profiler でフレームレート確認
# または Performance Overlay (Shift+P) 使用
```

#### 3.3 ロード時間
```
目標値:
- アプリ起動: < 3秒

- 問題ロード: < 200ms
- 結果表示: < 1秒
```

#### 3.4 ネットワーク (Firestore同期)
```
テスト項目:
```
