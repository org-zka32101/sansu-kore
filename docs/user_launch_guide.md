## Step 2: APK ダウンロード＆確認

**必要なもの**: Google Chrome or Edge ブラウザ  
**所要時間**: 3分

### 2-1. GitHub Actions から APK ダウンロード

```
1. https://github.com/yourwishappsdev-hash/sansu-kore/actions
   にアクセス

2. リストの「Build APK」（最新）をクリック

3. 画面下部の「Artifacts」セクションを探す

4. 「sansu-kore-apk」のボックスをクリック
   → ダウンロード開始

5. ダウンロードファイル:
   sansu-kore-apk.zip (77MB)

6. zip ファイルを解凍:
   右クリック → 「展開」または「すべて展開」

7. 展開後:
   app-release.apk (77MB) が取得できます
```

## 📱 トラブルシューティング

### Q1: GitHub Actions でビルド失敗した場合

```
確認項目:
□ インターネット接続
□ Firebase google-services.json 正常
□ Flutter バージョン 3.24.0 以上
□ Gradle バージョン最新

対応:
git push を再度実行 → Actions 再トリガー
```

### Q2: AAB ビルドが失敗する場合

```
確認項目:
□ Flutter pub get 実行済み
□ キーストア存在確認
□ JDK インストール確認

対応:
flutter clean
flutter pub get
.\build-aab.ps1
```

### Q3: Google Play Console で "No matching client found" エラー

```
原因:
google-services.json のパッケージ名とビルドのパッケージ名が不一致

解決:
1. android/app/build.gradle.kts で packageName 確認
   com.yourwishapps.shougakukore.sansu

2. google-services.json で同じパッケージ名か確認
   "package_name": "com.yourwishapps.shougakukore.sansu"

3. 一致していなければ google-services.json を再ダウンロード
```

### Q4: 審査で却下された場合

```
一般的な却下理由:
- コンテンツ: 不適切な言語表現がないか確認
- 機能: クラッシュ、エラー画面がないか確認
- プライバシー: 親同意画面が表示されるか確認

対応:
1. 却下理由メールを確認
2. 必要に応じてコード修正
3. 修正版 AAB をアップロード
4. 「再申請」ボタンをクリック
```
