## 🚀 インストール方法

### 方法A: USB で転送（推奨）

1. **APK をダウンロード**
   ```
   H:\マイドライブ\apk\sansu-kore-firebase-v3.1.apk
   ```

2. **Android 端末を接続**
   - USB ケーブルで PC と接続
   - 「ファイル転送」モードを選択

3. **APK をコピー**
   - `sansu-kore-firebase-v3.1.apk` をコピー
   - 端末の `Download` フォルダに貼り付け

4. **インストール**
   - 端末の「ファイルマネージャー」を開く
   - `Download` フォルダ → `sansu-kore-firebase-v3.1.apk` をタップ
   - 「インストール」をタップ
   - ⏳ インストール完了まで待機（1〜2分）

### 方法B: adb（コマンドライン）

```bash
# Android SDK Platform Tools をインストール
# https://developer.android.com/studio/releases/platform-tools

cd H:\マイドライブ\apk\
adb install sansu-kore-firebase-v3.1.apk

# 出力: Success
```

## ✅ テストチェックリスト

- [ ] 「クイックスタート」または「ステージ選択」をタップ

### フェーズ4: Firebase データ確認（5分）

**Firebase Console で確認**:

1. https://console.firebase.google.com/ を開く
2. `your-wish-education` プロジェクト
3. **Firestore Database** → **データ**
4. `users` コレクション内に、テストユーザーの UID フォルダが作成されているか確認
5. 以下のドキュメントが存在するか確認：
   - `profile` — 名前、学年、アバター
   - `progress` — ステージクリア情報
   - `coins` — コイン残高 (3問 × 10 coins = 30 以上)

**期待値**:
```json
users/{uid}/
  ├─ profile: { name: "テスト太郎", grade: 1, ... }
  ├─ progress: { ... }
  └─ coins: { totalCoins: 30+ }
```

## 🐛 トラブルシューティング

### インストール失敗

```
❌ アプリをインストールできません
```

**対処法**:
1. 端末の「設定」→「セキュリティ」
2. 「提供元不明のアプリ」を有効化
3. 再度インストール

### ログイン失敗

```
❌ ログインに失敗しました
```

**対処法**:
1. WiFi またはモバイルデータが接続しているか確認
2. Google アカウント情報が正しいか確認
3. Firebase Console で Email/Password 認証が有効か確認

### データが Firestore に保存されない

```
❌ users コレクションが空
```

**対処法**:
1. Firebase Console → Authentication → Enable Email/Password
2. Firestore ルール確認（セキュリティルール）
3. ブラウザ開発者ツール（Chrome DevTools）で Firebase エラーを確認
