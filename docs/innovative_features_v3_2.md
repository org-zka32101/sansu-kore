## ⑤ 「1日1問」ウィジェット

### 仕様

**機能概要**
- ホーム画面ウィジェット（Android Widget / iOS App Clip）
- 毎日AM 6:00に新しい問題が1問表示
- アプリを開かずにウィジェットからタップで回答
- 正解でストリーク継続

**UI/UX**
```
┌─────────────────────┐
│  📐 今日の1問      │
├─────────────────────┤
│                     │
│  3 + 5 = ?          │
│                     │
│  [A] 8  [B] 7       │
│  [C] 9  [D] 6       │
│                     │
│ ✅正解！🔥Day 15   │
│                     │
└─────────────────────┘
```

**技術実装**

| 項目 | 実装方法 |
|------|---------|
| **Android Widget** | flutter_appwidget (2024対応版) |
| **iOS Widget** | ios_workgroup (WidgetKit) |
| **毎日更新** | WorkManager + Cloud Functions |
| **データ同期** | SharedPreferences (ローカル) + Firestore |

**既存コードの流用**
```dart
// stage_data.dart の getRandomQuestion() をそのまま使用
// result_screen.dart のバッジ判定ロジックを流用
// 新規コード: ~300行（widget部分のみ）
```

**リリース価値**
- 離脱防止：ウィジェット見るだけで習慣が保たれる
- DAU向上：朝の通知効果で +20～30% DAU増
- レビュー：「便利！」評価↑
- 実装コスト：**低** (既存部品流用)

## ④ 親子対戦「ハンデ戦」

### 仕様

**機能概要**
- 親と子が同時に問題を解く対戦モード
- 親：6年生問題（難度MAX）
- 子：自分の学年問題（ノーマル）
- 時間制限：2分間で得点を競う
- 毎週ランキング更新

**シナリオ例**
```
親: 「今日も対戦しよう」
    6年生問題: 「2/3 + 1/6 = ?」(難問)
    → 1分30秒かけて正解 → 得点 50点

子: 「ぼく、今日は3年生!」
    3年生問題: 「10 - 3 = ?」(簡単)
    → 10秒で正解 → 得点 100点

結果: 「子が勝った！」バッジ獲得
    家族ランキング: 1位「子」2位「親」
```

**UI/UX**

```
【対戦開始画面】
┌──────────────────────┐
│ 親子対戦 ハンデ戦   │
├──────────────────────┤
│                      │
│  👨 パパ (難度MAX)   │
│  👧 あさみ (3年生)   │
│                      │
│  [対戦開始] (2分)   │
│                      │
└──────────────────────┘

【対戦中】
親画面                 子画面
┌────────────┐    ┌────────────┐
│ 1:30       │    │ 1:30       │
│ 2/3+1/6=? │    │ 10-3 = ?   │
│[A]5/6 ..  │    │[A]7 [B]6   │
└────────────┘    └────────────┘

【結果】
┌──────────────────────┐
│ 🏆 あさみの勝ち!  │
├──────────────────────┤
│ パパ: 50点 ⭐⭐   │
│ あさみ: 100点 ⭐⭐⭐ │
│                      │
│ [新バッジ] 親を倒した! │
│                      │
└──────────────────────┘
```

**新バッジ（③と共用で8個追加）**
```
対戦関連:
- 「初対戦」(1回目対戦)
- 「親を倒した」(親に勝利)
- 「親チャンピオン」(3連勝)
- 「家族No.1」(週間ランキング1位)

先生関連:
- 「先生デビュー」(初めて問題作成)
- 「問題作成数20」(20問作成)
- 「人気問題」(自作問題が10人以上に解かれた)
- 「良問賞」(自作問題が5つ星評価)
```

## ③ 「先生になろう」モード

### 仕様

**機能概要**
- 子どもが問題を**作る側**に回る
- 「答えが12になるかけ算の問題を作ろう」→ 4×3, 6×2, 12×1 など、複数解を提示
- 作った問題を友達に出題 → 解かれたらコイン獲得
- ユーザー生成コンテンツで問題数が自動増殖

**シナリオ例**
```
あさみ: 「ぼくも先生になりたい!」
アプリ: 「よし! じゃあこの条件で問題を作ってみて」
      「答えが15になる、たし算の問題を作ろう」

あさみが入力:
  問題文: 「ケーキが8個あります。□個もらったら15個になりました」
  答え: 7
  選択肢: [7, 6, 8, 9]

アプリが確認:
  ✅ 正解: 7
  ✅ 選択肢に正解含む
  ✅ 問題文が理解しやすい

確認後, 友達に出題:
  「あさみからの挑戦状」
  → 友達が解く
  → 解かれたら「あさみのコイン +10」
  
  [バッジ獲得] 「初めて先生になった!」
```

### Firebase Firestore 新規コレクション

```
users/{uid}/created_questions/  ← ③先生モード
battles/{battleId}             ← ④対戦履歴
family_rankings/{familyCode}   ← ④家族ランキング
```

### Firestore セキュリティルール追加

```firestore
// created_questions は自分の問題のみ書き込み可
match /users/{uid}/created_questions/{document=**} {
  allow read: if request.auth.uid != null;
  allow create, update: if request.auth.uid == uid;
}

// battles は誰でも読める、管理者のみ書き込み
match /battles/{document=**} {
  allow read: if request.auth.uid != null;
  allow write: if false; // Cloud Functions で管理
}
```
